# Obsidian Orbit

Full-colour Python 3 neon gravity-orbit arcade for ElbowOS.

Steer a gold probe around a central black hole.
Collect cyan / gold / teal stars.
Avoid magenta debris.
A / D or Left / Right apply thrust.

## Play

```bash
pip install -r requirements.txt
python3 obsidian_orbit.py --play
```

## Record a 9:16 reel

```bash
python3 obsidian_orbit.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
